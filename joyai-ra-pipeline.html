数据处理：统一动作空间

Unified Action Space — 跨本体异构性的核心机制

把来自不同本体 / 不同来源的不兼容动作表示，统一成「相机系 6-DoF + 定长向量 + 掩码」的共同物理语义空间，这是异构数据能「拼起来训练」的必要前提。

2.1 相机系末端表示

对所有带动作标签的数据（真机 / retarget 后人类轨迹 / 仿真），以相机坐标系表达末端执行器状态与动作。

6-DoF 末端位姿分解
$$ \text{6-DoF} = \underbrace{(\Delta x,\Delta y,\Delta z)}_{\text{3D 平移}} \;\oplus\; \underbrace{(\omega_x,\omega_y,\omega_z)}_{\text{3D 轴角}} $$
  • 物理语义一致：同一动作向量在不同机器人上对应同样的空间位移/旋转，与底座位置、运动学构型无关。
  • 与视觉对齐：图像输入与动作预测共用同一视角，便于「视觉接地」的动作预测。
为何是相机系？跨数据源的唯一共存参考系 机器人 base 系 / 关节系对人类视频不存在；世界系在人类视频里未定义。只有相机系是三种数据都自然存在的坐标系——把「统一」从算法挑战降级为工程实现。

隐含问题 相机系是非惯性系（头部/腕部相机会动；腕部相机与末端刚性连接时更极端）。VLA 范式靠「每帧重看、单 chunk 内视作局部惯性」回避了跨时间一致性问题——论文用的「consistent physical semantics」指跨本体一致，非跨时间一致。动作参考系是哪个相机、腕部 vs 主相机分工，论文未明说。

2.2 定长动作维度 + 掩码

定义一个覆盖所有出现过的执行器组的定长向量，不存在的自由度在损失中被掩码、不参与梯度。

统一动作向量结构（示意）
$$\mathbf{a}=\big[\,\mathbf{arm}_L^{6}\,\|\,\mathbf{arm}_R^{6}\,\|\,g_L\,\|\,g_R\,\|\,\mathbf{hand}_L^{N}\,\|\,\mathbf{hand}_R^{N}\,\cdots\big]$$
左臂 6右臂 6 左夹爪 1右夹爪 1 左灵巧手 N右灵巧手 N

掩码机制：例如人类视频 retarget 到 ALOHA（双臂夹爪）时，只有 14 维有效，灵巧手维度被 mask；retarget 到 Agibot G1 则启用灵巧手关节角。同一固定维度从单臂夹爪到双臂灵巧手系统通用。

动作标签的物理细节 — 论文黑盒 每一维的量纲 / 归一化方式 / 坐标系参考点 / 有效范围，论文均未披露。

3.3 Action Expert 内部机制 · 逐式拆解

① Flow Matching：学「噪声 → 真实动作」路径上的速度

线性插值路径（构造扰动动作）
$$ \tilde{a}_{1:H}^{\,\tau,\epsilon}=\tau\, a_{1:H}+(1-\tau)\,\epsilon,\qquad \epsilon\sim\mathcal{N}(0,I),\;\tau\in[0,1] $$

τ=0 纯噪声，τ=1 真实动作，速度沿路径为常数 ε − a1:H。相比直接回归能学多模态动作分布（同一观测下多种合理动作不会被均值化）；相比 diffusion 路径更直、推理仅需 5–10 步。

② 构造潜在序列（沿 token 维度拼接，非特征维度）

第 0 层输入序列 a⁰（注意：是输入序列，不是动作本身）
$$ a^{0}_{t:t+H}=\mathrm{Concat}\big(\underbrace{\phi_s(s_t)}_{\text{状态编码}},\;\underbrace{f_{\text{future}}}_{\text{未来占位 token}},\;\underbrace{\phi_a(\tilde{a}_{t:t+H},\tau)}_{\text{扰动动作+时间编码}}\big) $$
φ_s(s_t)
状态编码器（小 MLP）把本体感知（关节角/末端位姿/夹爪）映射成 token —「机器人现在在哪」
f_future
可学习 query embedding，长度=H，未来动作步的显式占位符（类比 DETR object queries）
φ_a(ã,τ)
扰动动作 + 时间步 τ 编成 token —「当前噪声动作估计，请告诉我修正方向」

③ 堆叠的时序感知 Perceiver Block（每层四步）

Perceiver：用一组固定数量 latent token 做 query，cross-attend 长输入做 K/V，复杂度从 O(N²) 降到 O(L·N), L≪N。此处 latent = 上面拼出的序列；外部上下文 = VLM 表征 zt（latent bottleneck 高效多模态融合）。

AdaLN 时间调制 VLM 表征
$\tilde{z}_t=\mathrm{AdaLN}_z(z_t,\tau)$ — γ,β 由 τ 经小网络动态预测，不同去噪阶段以不同方式利用语义（DiT 成熟设计）。
残差注意力（self + cross 一体）
$h'=h+\mathrm{MHA}(Q{=}h,\;K,V{=}[h;\tilde{z}_t])$ — K/V 是 latent 拼 VLM 表征：每个 token 同时 attend 其他 latent（动作内部时序依赖）与 VLM 表征（吸收视觉-语言上下文），一次注意力做完两件事。
残差 FFN 细化
$h^{out}=h'+\mathrm{MLP}(h')$ — 对每个 token 独立非线性变换。
解码速度场
$v^{out}_{t:t+H}=f_\theta(z_t,a^{0}_{t:t+H},\tau)$ — 从精炼后的 latent（future token 位置）投影出 H 个速度向量。
「时序感知」指哪个时序？ 指 flow matching 的去噪时间步 τ（τ=0 噪声 → τ=1 真实动作），不是动作 chunk 内部「未来第 1/2/3 步」的物理时序。每层 Perceiver block 通过 AdaLN 注入 τ —— 这就是「时序感知」。多层堆叠从粗到细：粗对齐任务 → 高层推理动作大致方向 → 细化每步精确速度。

训练流程：三阶段课程

Stage 1 VLM → Stage 2 VLA → Stage 3 Post-Training

按「先语义、再行为、最后专精」消化异构数据。各阶段输入 / 输出 / 数据来源 / 损失逐一标注。消融显示三阶段叠加比任一单阶段更优（90.48 vs ~87.x）。

STAGE 1 VLM Co-Pretraining 注入视觉理解、空间推理、长时规划、离散动作生成能力
训练数据来源（task-specific sampling ratios 混合）
① General VQA（QA/caption/多轮对话，保通用视觉理解）｜② Embodied VQA（点/框/轨迹输出 + 任务分解，强空间推理 & 长时规划）｜③ 跨本体动作数据（真机+仿真，FAST 离散化形式预热）｜④ 人类视频（扩大视觉与动作分布覆盖）
输入 / 输出
输入：图像/语言 token（标准自回归序列）｜输出：文本响应 + 离散 FAST 动作 token（同一词表，共享 embedding）
参数训练范围 推断
语言主干更新；vision encoder 极可能更新或轻量更新（论文称「保留视觉理解」）；Action Expert 尚未上线
损失函数 — 标准自回归 NLL（loss mask 控制哪段算损失）
$$ \mathcal{L}_{\text{Stage1}}(\theta)=\mathbb{E}_{(x,y)\sim D}\Big[-\sum_{j=1}^{n-1} M_j \log p_\theta(y_{j+1}\mid x_{1:j})\Big] $$
Loss Mask 如何「吸收」异构标签 — Stage 1 能统一训练的关键 所有数据被拉平成「输入 token → 输出 token」一个序列；Mj 是 0/1 开关数组，决定每个位置的预测是否进损失。VQA：图像+问题 M=0、答案 M=1；动作数据：观测+指令 M=0、FAST token M=1。无论扔进什么数据，都用同一个 NLL + 不同 mask——差异全被 mask 吸收，正是 GPT 类模型能同时学 QA/续写/翻译的同一原因。
STAGE 2 VLA Co-Pretraining 学习连续操作行为，同时保留 VLM 视觉-语义表征
训练数据来源（Action Expert 上线，引入 flow matching）
General VQA + Embodied VQA（保基础能力）｜仿真机器人轨迹｜真机示范｜retarget 到下游本体的人类视频示范 —— 动作数据全部投影到统一动作空间，保持异构来源对齐
输入 / 输出
输入：多视图观测 + 语言 + 状态 + 扰动动作｜输出：文本（自回归）+ 连续动作速度场（flow matching）
参数训练范围 推断
VLM 与 Action Expert 均更新，但 VLM 被 NLL 项「拽住」防漂移；vision encoder 是否冻结 / 是否 LoRA / 学习率分组，论文未说
损失函数 — 自回归 NLL + Flow Matching MSE 联合（α 加权）
$$ \mathcal{L}_{\text{Stage2}}=\alpha\!\cdot\!\mathbb{E}\Big[-\!\sum_{j=1}^{n-1}\! M_j\log p_\theta(y_{j+1}|x_{1:j})\Big]+\mathbb{E}_{D,\epsilon,\tau}\big[\,\|\epsilon-a_{1:H}-f^a_\theta(\tilde{a}^{\tau,\epsilon}_{1:H})\|^2\big] $$
第一项：保持文本/离散动作自回归能力（=保护 VLM 表征不被腐蚀）｜第二项：训练 faθ 预测 flow ε−a1:H
STAGE 3 VLA Post-Training（目标机器人） 在目标部署本体上轻量专精，提升下游成功率
训练数据来源
仅目标机器人本体采集的数据（或目标仿真 benchmark 生成数据），记为 D_target
关键设计
丢弃辅助自回归目标，只保留 flow matching 损失 — 接受 VLM 表征因专精而更专门化，用通用性换性能
参数训练范围 论文明确
all parameters end-to-end — VLM 与 Action Expert 联合微调，视觉-运动表征与动作生成共同适配目标任务
损失函数 — 仅 Flow Matching
$$ \mathcal{L}_{\text{Post}}(\theta)=\mathbb{E}_{D_{\text{target}},\epsilon,\tau}\big[\,\|\epsilon-a_{1:H}-f^a_\theta(\tilde{a}^{\tau,\epsilon}_{1:H})\|^2\big] $$
三阶段冻结/端到端 — 唯一被明说的是 Stage 3 论文仅在 Stage 3 强调「all model parameters updated end-to-end」。Stage 1/2 训练范围未明说，但从损失设计反推（Stage 2 保留 NLL 项「保护 VLM」）——最可能是 VLM + Action Expert 均更新、双损失加权平衡。vision encoder 是否冻结、是否 LoRA、warmup 等是 VLA 论文常见「披露不全」。

05

推理与部署

Inference Chain — 从观测到底层控制

实时控制的完整链路：VLM 编码 → 自回归生成子任务 → Action Expert flow-matching 去噪 → 掩码取本体自由度 → 6-DoF 转回机器人系下发控制器。

输入侧 Input
多视角观测 O_t（图像）+ 语言指令 L（human prompt）+ 本体感知 s_t（关节/末端状态）
中间产物
VLM 表征 z_t + 高层子任务文本 ℓ（自回归生成）
输出侧 Output
相机系 / 统一空间下的连续动作 chunk a_{t:t+H}

FLOW 处理流程

VLM 联合编码
对图像 + 指令编码，输出多模态表征 zt。整个去噪迭代中 zt 只算一次并缓存，是实时控制的关键。
自回归生成高层子任务 ℓ
例：「Package the delivery」→ 分解为「Put the medicine into the package」。
子任务 + z_t 作为上下文传给 Action Expert
语义条件注入动作生成。
Flow-Matching 逆过程去噪（ODE 积分）
从高斯噪声 ε 起步，按学到的速度场 vout=fθ(zt,a⁰,τ) 逐步积分到 τ=1，得干净动作 chunk。常 5–10 步（欧拉法）。
掩码取本体自由度
用与训练一致的动作维度掩码，从统一向量取出当前本体真实存在的自由度。
坐标转换 + 下发控制器
6-DoF 末端动作（3 平移 + 3 轴角）转回机器人坐标系，下发底层控制器。
推理一步（欧拉法 · 简化伪代码）
a ← ε                                  # 从纯噪声起步
for τ = 0, Δτ, 2Δτ, ..., 1:
    h⁰ ← Concat(φ_s(s_t), f_future, φ_a(a, τ))
    v  ← Action_Expert(h⁰, z_t, τ)        # z_t 缓存复用
    a  ← a + Δτ · v                       # 沿速度场积分一步
return a                                 # 预测的动作 chunk
动作 chunk 模式的好处 每次推理一次性产出未来 H 步（如 16 步），提高时间一致性、降低推理频率压力。整个 chunk 视作「chunk 起始帧相机系」下的局部惯性表达——这是单 chunk 时长内（几百 ms）相机变化有限的工程妥协，配合控制器反馈与每步重观测，累积误差不会无限放大。
# PIPELINE SUMMARY
四源异构数据（网页 12% · 人类 33% · 仿真 24% · 真机 31%）→ 统一动作空间（相机系 6-DoF + 定长向量 + 掩码）→ VLM 4B + Perceiver Action Expert 600M 双塔→ 三阶段课程（VLM 自回归 → VLA 自回归+flow matching → Post-Training 仅 flow matching）→ 推理：VLM编码→自回归子任务→flow-matching ODE去噪→掩码+坐标转换→控制器。
