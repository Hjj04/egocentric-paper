00 / OVERVIEW

框架总览：三阶段 + 部署

HARP 的核心数据哲学是少量配对数据做对齐，大量非配对数据做动力学。它先把人和机器人的视觉表征与潜动作压到同一空间（Stage 1），用对齐后的编码器和潜动作伪标签预训练 VLA（Stage 2），再用少量真机动作把抽象潜动作落到可执行指令（Stage 3），最终在线运行。

论文事实 · 关键配置一览

潜动作：每个 transition Nq=4 个 token，码本 K=16，潜维 dq=128，VQ commitment β=0.25。视觉骨干：Prismatic-7B 的 DINOv2 + SigLIP 融合，输入 224×224，每帧 16×16=256 patch token，融合维 2176。真机：Xarm7（6 DoF）+ Robotera XHand（12 DoF）= 18 DoF。输出：10 步真实动作 chunk。

01 / DATA

数据采集与数据组成

1.1数据的逻辑划分

全部训练数据记为 D = Dp ∪ Du，分两类，二者承担完全不同的角色。

  • 配对数据 Dp = {(Hi, Ri, li)}：同一任务、同一语言指令 li 下的人类视频 Hi 与机器人视频 Ri 成对出现。作用是跨本体桥梁，支撑 Stage-1 的 cross-prediction 与对齐损失。
  • 非配对数据 Du = {(Vj, lj)}：单条视频，本体 e ∈ {h, r}，不要求成对。作用是可扩展的动力学监督源，支撑 self-prediction 与辅助监督。

1.3硬件平台

真机为 Xarm7 机械臂 + Robotera XHand 灵巧手，共 18 DoF（臂 6 + 手 12）。观测来自第三视角相机 + 腕部相机。论文事实

1.4每条视频的辅助标注 AX = {KX, EX}

  • KX：2D 物体位置轨迹（object position tracks），捕捉操作效果。
  • EX：2D 轨迹 —— 人类取手腕，机器人取末端执行器（wrist / end-effector），作为粗粒度运动意图的代理。

设计动机是：物体运动和粗粒度的手部/末端运动比原始外观更跨本体共享，用它们正则化潜动作，让潜动作抓运动动力学而非外观 —— 对没有配对监督的非配对视频尤其重要。

02 / PREPROCESS

数据处理（附录 A.1）

处理的目标是为配对数据建立帧级对应，给后续 cross-prediction 提供帧级视觉线索。两步：提取关键点、做时间对齐。

2.1关键点提取

物体关键点 · 专门处理重度遮挡

沿用 object-flow 思路。流程是：若无语言指令，先用 Qwen3-VL-8B-Instruct 生成被操作物体的描述 → 用 GroundingDINO 在物体首次出现帧定位 bbox → 在该首帧提取关键点 → 用 TAPIR 跟踪。

选 TAPIR 是因为它能利用历史上下文推断当前位置，并给出遮挡/可见性分数，从而在遮挡帧降低不可靠预测的权重。论文强调：现有管线在完全遮挡下通常失败且很少显式处理，这正是该设计看似复杂却必要的原因。

手部关键点

  • 人类视频：用 WiLoR（单目 3D 手部重建，回归 MANO 参数），取手腕在图像平面的 2D 像素坐标。
  • 机器人视频：用相机外参 + 记录的 3D 腕部位姿，做标准透视投影得到每帧 2D 坐标。

2.2时间对齐 DTW

配对采集时虽要求动作相似，但执行速度/子动作时长难以严格一致。处理方式：

  • 以手部关键点的欧氏距离作为人-机相似度度量；
  • 用 DTW 求最优匹配路径，以机器人视频为时间参考（执行更均匀），通过删/复制帧重采样人类视频；
  • 得到时长与速度都同步的配对视频，采样时在机器人时间轴上取匹配的人-机 transition。

处理后 Dp = {(Ĥi, R̂i, li, AĤi, AR̂i)}，帽号表示已时间对齐（后文省略）。这也意味着采集时可以只专注于「动作模式匹配」，把严格时间对齐交给 DTW。

工程推断 · 未给出的细节

3.1人机视觉编码 & 码本

视觉编码用同一套骨干，靠「加不加 adapter」区分本体：

Φθ(X, e) = F(X) // e = human：直接走冻结原始编码器
              = Tθ(X) // e = robot：F + 机器人专属 adapter
  • 人类帧：直接走冻结的原始编码器 F，不做任何改动，输出 ZX = F(X)。
  • 机器人帧：走 Tθ（F + adapter），输出 ZX = Tθ(X)；同时仍保留一份冻结参考 ZX0 = F(X)（机器人图过纯 F、不过 adapter），后面对齐损失要用。

注意：对人类而言 ZX 与 ZX0 是同一个东西（都过 F）；只有机器人才有 adapted（Tθ）和 frozen（F）两个版本。设计意图是把人类侧钉死在预训练视觉空间当锚点，只把机器人侧往人类语义空间拉。

骨干与 adapter（论文事实）

骨干是 Prismatic-7B 的 DINOv2 + SigLIP 融合编码器（输入 224×224，每帧 256 个 patch token，融合维 2176）。adapter 是在 DINOv2 和 SigLIP 每一层的 attention 块和 FFN 块之后各插一个 2 层 MLP，输入当前特征、输出残差加回原特征；第一层高斯初始化、第二层零初始化，所以初始时刻残差恒为 0，机器人路径与人类路径完全相同，训练才逐步把机器人特征推向人类。

论文事实 · 码本（Codebook）是什么

码本属于潜动作模型 LAM、不属于视觉编码器，但接在视觉编码之后。它是 VQ-VAE 的量化字典 —— 一组可学习离散向量：规模 K=16 个、每个维度 dq=128。LAM 编码器从一段视觉 transition 推出连续潜动作 a，码本把它量化（取最近邻）成离散 q，每个 transition 用 Nq=4 个这样的 token 表示。其意义在于：人和机器人的动力学都被强制压进同一个只有 16 个条目的码本，潜动作就成了跨本体共享的离散动作词表 —— 这是动作层面对齐的核心载体。

3.2自预测 vs 跨预测

两者共用同一组三元组，只是 decoder 的「条件」和「目标」换了来源：

// 逆动力学：从两帧推潜动作
atX = Eθ(ztX, zt+ΔtX, lX)
qtX = Qθ(atX) // 码本量化
// 前向动力学：预测未来视觉特征
ŶtX = Dθ(z̃tX, qtX, lX)

各分量含义：

  • ztX：视频 X 第 t 帧的 patch 级视觉特征（编码器输出）。
  • zt+ΔtX：transition 第二帧的特征，Δt 是随机采样的时间间隔。
  • lX：语言指令（冻结 T5 编码）。
  • Eθ：LAM 编码器（逆动力学）—— 看「当前帧+未来帧+指令」推断中间发生了什么动作。
  • Qθ / qtX：码本量化器 / 量化后的离散潜动作。
  • Dθ：LAM 解码器（前向动力学）—— 给「条件帧+离散动作+指令」预测未来视觉特征。
  • z̃tX：解码器的条件特征 —— 自/跨预测的区别就在这里。
  • ŶtX / YtX：解码器预测的未来特征 / 对应真值未来特征（也随自/跨而变）。
论文事实 · 预测目标是什么

预测的是未来帧的视觉特征 zt+Δt（patch token），不是动作、不是原始像素、也不是潜动作。潜动作 qt 在这里是 decoder 的输入/条件（由 encoder 逆动力学推出的中间瓶颈码），唯独不是预测目标。整个重建发生在 DINOv2+SigLIP 的特征空间，论文没有像素解码器。

自预测 · 非配对视频 V

z̃tV = ztV     YtV = zt+ΔtV   // 动作、条件、目标全在同一条视频内

从 V 的 transition 推动作，用 V 自己的当前帧当条件，预测 V 自己的未来帧。标准视频自监督动力学。

跨预测 · 配对视频 (H, R)

潜动作从源本体 transition 推出，但 decoder 用目标本体的当前帧当条件、预测目标本体的未来帧。两个方向：

// 源 = 人类：人类潜动作去预测机器人未来
z̃tH = ztR     YtH = zt+ΔtR

// 源 = 机器人：对称，机器人潜动作去预测人类未来
z̃tR = ztH     YtR = zt+ΔtH

上标读法要留意：ŶtH 里的上标 H 指潜动作来自人类（源），而条件帧和目标帧的视觉内容其实都是机器人（目标）。Figure 2 右侧标注「Input(Human), Condition(Robot), Predict(Robot)」说的正是这件事。意义在于：人类潜动作若真能预测机器人未来（反之亦然），就证明潜动作跨本体共享 —— 这一步把潜动作学习和人机对齐硬绑在一起。

3.3总损失逐项拆解

Lstage1 = Llam + λaux·Laux + λalign·Lalign
工程推断 · 权重数值

三项权重 λaux、λalign（及下面的 λK、λE、两个 margin ms、mt）的具体数值论文全部没给。

① Llam · 潜动作预测损失

通俗讲：模型拿到当前帧和未来帧，先推断一个码概括两帧间画面发生了什么变化（即潜动作），再用「当前帧 + 这个码 + 指令」预测未来帧的特征；预测越接近真实未来帧，损失越小。这逼着码必须真的装下「画面怎么变」的信息。

ℓlam = ‖ ŶtX − YtX ‖22 + ℓvq
ℓvq = ‖ sg[a] − q ‖22 + β·‖ a − sg[q] ‖22   // β = 0.25
  • 前一项：未来特征预测项，decoder 预测 Ŷ 与真值未来特征 Y 的 L2 平方差（自/跨预测共用）。
  • ℓvq：标准 VQ 损失。sg[·] 是 stop-gradient；第一项是码本项，把码本向量 q 拉向编码器输出 a（只更新码本）；第二项是 commitment 项，把 a 拉向 q（只更新编码器）。

数据源：所有视频（配对+非配对）。标签：无真实动作 —— 目标 Y 就是视频自己的未来帧特征，纯自监督。

② Laux · 掩码共享线索辅助损失

通俗讲：学码的同时，额外要求模型从两个辅助 token 预测出「物体在画面里的 2D 位置」和「手腕(人)/末端(机器人)的 2D 位置」；预测越准损失越小，被遮挡看不见的点不计入。作用是把码往「物体和手怎么动」上引导，避免它去记外观。

K̂X = GK(uX,K) ∈ ℝNK×2  // 物体关键点
ÊX = GE(uX,E) ∈ ℝ2      // 手腕/末端位置

ℓK = Σ M·H(K̂, K) / (Σ M + ε)  // 带可见性掩码的 Huber
ℓaux = λK·ℓK + λE·ℓE
  • H：Huber 损失；M ∈ {0,1}：可见性掩码，遮挡/不可见点权重置 0（呼应 TAPIR 的可见性分数）。
  • ε：防分母为零的小常数；NK：物体关键点数（论文未给具体值）。
  • 这些位置之所以有用，是因为物体和手的运动在人和机器人间相近，而外观差很多 —— 只有抓运动信息，码才能跨本体通用。

数据源：所有视频。标签：物体轨迹 + 手腕/末端轨迹的 2D 坐标，但这是预处理阶段自动提取的伪标签（GroundingDINO+TAPIR 提物体、WiLoR/MANO 提人手、外参投影提机器人末端），既非人工标注、也非真实动作。

③ Lalign · 源相对 + 配对判别对齐损失（本文最大创新，仅用配对数据）

对一对 (H,R)，先做视频级 pooling φ（帧内空间平均 → 帧间时间平均 → L2 归一化）得三个向量，距离用余弦距离 d(u,v)=1−cos(u,v)，记 di+ = d(fR, fH)：

fH = φ(ZH)  // 冻结人类特征（人类只过 F）
fR0 = φ(ZR0) // 冻结机器人特征（机器人过纯 F）
fR = φ(ZR)  // adapted 机器人特征（机器人过 Tθ）

源相对项 SR（通俗讲：过了 adapter 的机器人特征，要比没过的时候更靠近对应人类特征；只要求「比原来近」，不规定近到某个固定值）：

ℓSR = [ ms + d(fR, fH) − d(fR0, fH) ]+  // [x]+ = max(x,0)

配对判别项 PD（通俗讲：一对正确配对的人机距离，要明显小于「这个机器人」与同批次里「别的不配对人类」之间的距离，保证不同配对仍分得清、不塌成一团）：

d̄R→H(i) = (1/(B−1)) · Σj≠i d(fRi, fHj) // 非配对平均距离
ℓε = [ mt + di+ − d̄ε(i) ]+   ε ∈ {R→H, H→R}
ℓPD = λR→H·ℓR→H + λH→R·ℓH→R

两个方向各算一次，mt 是判别 margin。当 batch B=1 时丢掉 PD 项、只留 SR。合成 ℓalign = ℓSR + ℓPD。

数据源：仅配对数据 Dp。标签：没有动作标签 —— 唯一的「监督信号」是「哪条人类视频配哪条机器人视频」这个配对关系（来自配对采集设计），特征本身仍自监督。

论文事实 · Stage 1 标签总括

整个 Stage 1 不用任何真实动作标签。三类监督信号是：未来帧本身（Llam 的重建目标）、自动提取的 2D 关键点/轨迹伪标签（Laux）、人机配对关系（Lalign）。

工程推断 · 未明确

各 λ 与 margin ms/mt 数值、transition 的 Δt 采样分布、NK 取值均未给。φ 的「先帧内空间平均、再帧间时间平均、最后 L2 归一化」是附录 A.4 明确的。

损失
对潜动作 token 的交叉熵（语言式预测离散动作索引）。

打标签 + 训练目标（论文事实）

// 用冻结的 HARP-LAM 给每帧打统一潜动作标签
qtX = Qθ( Eθ(ztX, zt+ΔtX, lX) )

// VLA 以交叉熵预测这些离散潜动作 token
Lpretrain = −𝔼 [ Σi=1..Nq log πθ( q̂i = qtX,i | xt, lX ) ]

即把潜动作当成离散 token 序列「语言式」预测：这套做法保留了预训练 VLM 原有的视觉推理与语言理解能力，再额外赋予它动作建模能力。

论文事实 · 两个关键工程选择

(1) 复制 adapter 权重：VLA 用和 HARP-LAM 同一个视觉编码器，并把 Stage-1 学到的 adapter 权重复制进 VLM 的视觉编码器。因为 PrismaticVLM 的融合视觉编码器在网络规模预训练时是冻结的，复制权重后能保住已有的对齐性质。论文进一步论证：VLM 预训练以人类数据为主、人类表征更鲁棒，HARP 固定人类侧、只把机器人侧拉向人类侧，所以原 VLM 视觉编码器与 LLM 之间的对齐基本保留，利于后续 VLA 训练。

(2) 架构：VLA 沿用 OpenVLA-OFT，建在 Prismatic-7B 上（融合 SigLIP+DINOv2 + projector + LLaMA-2 LLM）。

工程推断 / 被消融的开关 · 是否冻结视觉编码器

「Stage-2 是否冻结对齐后的视觉编码器」是一个被消融的开关。实验显示冻结更好（见实验三）：adapter 已桥接人机视觉 gap 之后，冻结能同时保住「学到的人机对齐」和「网络规模预训练的视觉特征」。

05 / TRAINING · STAGE 3

真实动作微调

Stage 2 的 VLA 只会输出抽象潜动作，不能直接控制。用少量真实动作机器人数据微调，加一个 action head 把潜动作映射成可执行指令。最终模型称 HARP-VLA。

5.1训练数据与标签

参与 S3 的只有两个数据集（Table A1 的 S3 列）：

  • CALVIN（Robot/Sim，1.1M 帧）：纯下游集，S1/S2 完全不碰，只在 S3 用。
  • Ours-Real（真机 DexHand，0.5M 帧）：视频在 S1/S2 用过，但真实动作只在 S3 用。

标签是真实动作标签 —— 遥操采集时记录的实际机器人指令。真机 18 DoF（Xarm7 臂 6 + XHand 手 12），输出 10 步动作 chunk。这是整个流程里第一次出现真实动作标签（S1/S2 全程没有）。

5.2「把潜动作 embedding 映射成归一化真实动作」是什么意思

  • 背景：Stage 2 训出来的 VLA 只会吐潜动作 token —— 抽象的运动码（码本里的离散动作），不能直接驱动电机。
  • 做法：加一个从零训练的 action head（小模块，结构沿用 OpenVLA-OFT），输入是 VLA 内部产生的潜动作 embedding（预测出的潜动作 token 对应的表征/隐状态），输出是归一化的真实动作（10 步 chunk）；用 L1 损失训练，同时用 LoRA 微调 VLA 主干。
  • 「归一化」的含义：机器人各维动作（关节角、位置、夹爪等）量纲/范围不同，训练前按数据统计缩放到统一区间（如 [−1,1]），网络预测归一化值（优化更稳、各维损失更均衡），部署时再反归一化成真实物理指令。
  • 一句话：action head 就是把「抽象潜动作」翻译成「可执行（归一化）机器人指令」的那座桥，而它需要、S1/S2 一直没有的真实动作监督，正是 Stage 3 这点真机数据提供的。
工程推断 · 未明确

action head 的具体结构（层数、MLP/transformer）、LoRA rank、proprio 如何注入（Figure 3 标了「Instruction & Proprio」为输入但没给融合方式）、action chunk 内部表示、「normalized real action」的具体归一化方案，论文都没给（按 OpenVLA-OFT 标准做法理解）。

08 / EXPERIMENTS

实验完整梳理

论文从三个角度层层递进验证：(1) 是否对齐人机视觉表征与潜动作；(2) 对齐视觉编码器是否提升下游策略；(3) HARP-VLA 整体策略性能。三组实验构成因果链：先在纯表征指标上证明拉近了人机，再在冻结编码器的下游策略上证明这种对齐有用，最后在完整 VLA 上证明端到端有效。

8.1实验一 · 表征与潜动作对齐

设置：在 93 条 hold-out 配对人机示教上评估（不参与训练）。统一帧采样、统一 pooling φ、统一归一化与余弦度量，默认用 DINOv2+SigLIP 融合分支。三种评估：UMAP 可视化（定性）、配对余弦距离（几何对齐）、双向跨本体检索（语义可区分性）。所有 HARP 变体共享同一骨干、adapter、数据划分、预处理、训练预算，只改对齐目标或 pooling 空间。

09 / LIMITATIONS

局限（论文明确）

HARP-VLA 依赖任务配对的人机视频和辅助线索作为跨本体桥梁，性能受桥梁数据多样性、时间对齐与共享线索鲁棒性影响。当前评测只覆盖单机械臂桌面操作和有限的人类视频源。未来要扩到更大更杂的人类视频、对噪声线索更鲁棒、并验证更多本体 / 长程 / 双臂操作。
