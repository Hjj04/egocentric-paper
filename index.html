Donk

2026-06-02
未开源

同一个"视频-动作联合去噪器"：给定观测图像时它是灵巧手动作策略，不给图像时它是数据引擎。

核心思路

  • 架构视频与动作联合去噪，用单一模型统一建模感知与动作生成。
  • 角色一作为动作策略：从图像 + 语言预测未来双手 MANO 轨迹。
  • 角色二作为数据引擎：仅凭文本生成成对的"交互视频 + 同步手部动作"，把廉价的人类视频先验转化为动作对齐的机器人训练数据。
  • 动机真实遥操作数据昂贵且稀缺，需用生成数据补足。
局限：实验未包含真机验证。

HARP-VLA

2026-05-29
匿名提交 匿名代码仓库

从大规模无动作标签的人类操作视频中预训练可泛化的 VLA 策略，核心是同时缩小"视觉表征 gap"与"动作执行 gap"。以表征对齐的训练策略（损失设计 + 三阶段训练范式）为主，辅以一个小架构模块和一条数据处理 pipeline。

核心贡献

  • 损失新的对齐损失——源相对 + 配对判别损失：不强迫机器人特征塌缩到某个绝对距离，只要求 adapted 机器人特征相对冻结特征更靠近其配对的人类特征。
  • 训练把"潜动作学习"与"人机视觉对齐"耦合进同一个 Stage-1，构成三阶段训练范式。
  • 架构一个 robot-only adapter——唯一的架构贡献。

HumanEgo

2026-05-28
已开源 马里兰大学 ★ 234 项目主页 GitHub

从几分钟的人类第一视角视频（Aria 眼镜采集）直接学出可部署的双臂操作策略——不用任何机器人数据、不做大规模预训练，且可 zero-shot 迁移到真机（换机器人 / 相机 / 环境均无需重训或微调）。

核心贡献

  • 表征Interaction-Centric Token (ICT)：把每只手、每个物体都当作一个 entity，将其 6-DoF 位姿编码成 29 维 token。关键在于用 entity 自身的局部坐标系（而非相机系或绝对坐标）表达左右手位姿，使 token 直接反映"接近 / 抓取 / 搬运"的交互状态，并对视角、本体、环境天然不变——这是人到机器人 zero-shot 迁移的真正开关（消融：原始 RGB 上加 ICT，成功率 7.5% → 85%）。
  • 训练flow matching 动作生成 + 三个 dense 前向动力学辅助目标（物体未来 6-DoF 轨迹 / 未来 2D 投影轨迹 / K 步后的 ICT 隐状态），标签全部由感知管线自动产生；专门解决"数据极少"的问题，低数据区收益最大（8 分钟 57.5% vs 无辅助 37.5%）。
  • 预处理用 SAM2 + LaMa 抹除人手人臂并原位渲染虚拟平行夹爪与物体关键点，得到本体无关的视觉观测。（作者消融表明此步为次要——决定性的是 ICT 这一显式空间表征，而非视觉保真度。）
定位：非数据集贡献，本质是"新表征（ICT）+ 数据高效训练方法"组成的 robot-data-free 迁移 pipeline。
效果：30 分钟人类视频在 4 个真实任务上平均 92.5%，15 分钟 75%；同等采集时间下比遥操作基线 ACT 高 41%。

JoyAI-RA 0.1

2026-04-23
未开源 项目主页

围绕 egocentric 人类视频构建统一动作空间与 Action Expert 的 VLA 系统，强调数据语义宽度与一组定量化消融。

独有贡献

  • 数据EgoLive 数据集本身的语义宽度与标注粒度。
  • 算法基于相机系 6-DoF 的统一动作空间的具体工程实现。
  • 算法Perceiver + AdaLN 时序条件 + future tokens 在 Action Expert 上的具体组合。
  • 实验一组定量化消融，回答了"人类视频规模化、in-domain 对齐、EgoLive vs EgoDex、仿真数据贡献度"等此前没有清晰答案的问题。

DreamDojo

2026-02-06
已开源 NVIDIA ★ 913 项目主页 GitHub

数据规模 + 用 latent action 打通"人类视频 → 机器人世界模型（world model）"的训练配方。

核心思路

  • 数据使用 44k 小时人类第一人称视频。
  • 训练以"连续潜动作作为统一动作"的方法，把人类交互知识灌进一个基于 Cosmos-Predict2.5 的视频世界模型。
  • 推理在小规模目标机器人数据上微调后，可对未见物体 / 环境做物理合理、动作可控的实时模拟。
影响力：已获得接近 1k（★ 913）的 star，参考价值较高。
